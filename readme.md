# Portfolio Website

Source for [www.zakgrackham.uk](https://www.zakgrackham.uk), the personal portfolio of Zak Rackham, covering projects in robotics, IoT, automation, data analysis and 3D graphics.

It's a static site (HTML/CSS/JS) based on the [Massively](https://html5up.net/massively) template by HTML5 UP and hosted with GitHub Pages (see `CNAME`).

- `index.html`: overview, about me and project list
- `*.html`: individual project pages
- `downloadable/`: CV, reports and project source archives
